# Third-party dependencies

No third-party source snapshot is included in this release.

The optional integration paths refer to:

- ResComp: <https://github.com/list0830/ResComp>
- GPTAQ: <https://github.com/Intelligent-Computing-Lab-Panda/GPTAQ>
- QEP: <https://github.com/FujitsuResearch/qep>
- GPTQModel: <https://github.com/ModelCloud/GPTQModel>

These links identify external implementations, not a grant of permission to
redistribute them. Obtain compatible code separately and preserve its
applicable notices. In particular, this repository does not bundle ResComp
or helper files copied from another backend.

PyTorch, Transformers, Accelerate, Datasets, Safetensors and lm-evaluation-harness
are separately installed dependencies. Their licenses continue to apply.
Model and dataset licenses are independent of this repository.
